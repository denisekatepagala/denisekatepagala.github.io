# 🖥 Grade Calculator
A desktop application built with **Python** and **CustomTkinter** that helps students compute their GWA and course grades

# ✴ Project Overview
The application allows users to:
- Add multiple school year and terms
- Each school year and term has its own designated calculator for grades
- Input course, units, and grades
- Compute the overall Grade Weighted Average (GWA) per term
- View the total number of courses & units
- Compute the grade per course

# ✴ Planned Features
### Home Window
- View all academic terms
- Create a new term
- Delete an existing term
- Navigate to selected term

### GWA Calculator
- Add multiple courses
- Save course information
- Compute GWA
- Edit existing courses

### Course Calculator
- Compute grades without saving
- Quick calculator mode

### Data Storage
- Save terms using JSON
- Load previously saved terms
- Automatically remember user data
